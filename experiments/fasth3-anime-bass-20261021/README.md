# アニメのベーシストで FastH3 と H3 を比較

状態: **参照絵と共通プロンプトを準備済み。今回のGPU予算は未承認、動画生成は未実行。**

ローカル確認: Ref2VAプロンプトのstrict検査はエラー・警告0件。オフライン3テストで、
新旧の共通入力・固定レシピ、画像改変の拒否、一度実行した証拠の保持を確認した。

放課後の軽音楽部を思わせる、温かい2Dアニメ調のオリジナル女子キャラクター。
座ってサンバーストの4弦ベースを弾く。参照絵は `inputs/reference.png`、生成指示は
`reference-prompt.txt`、動画の共通指示は `prompt.txt`。画像の同一性は `source-lock.json` で確認する。
入力・生成物はGit対象外のため、画像の完全な再現には保存したPNGが必要。

## 比較条件

| 条件 | 内容 |
| --- | --- |
| 入力 | 同じ参照画像1枚、`--refs reference --ref-size match` |
| 映像 | nominal 5秒、1344×768、24fps、124フレーム（出力約5.17秒） |
| 構図・動作 | 固定カメラ、顔・両手・ベース全体。120 BPMで指弾き、2秒頃に左手を移動、4秒頃の終音を伸ばす |
| 音 | プロンプトからベース演奏と部屋の環境音を生成。台詞・歌・別楽器なし |
| 旧 | MiniMax-H3、通常の参照生成full 20 steps |
| 新 | FastH3 Omni、固定INT8 ConvRot / Euler 8 steps / VSA keep 10% |
| GPU | 各モデル別のColab A100 40GB。FastH3→H3の順に各1セッション |
| 提案A | seed 1・2、各2本、合計4本。上限6 CU、各セッション3 CU |
| 提案B | seed 1、各1本、合計2本。上限4 CU、各セッション2 CU |

同じ指示から各モデルが独立に音楽を生成する。音声ガイドを使わないため、同一の曲・
音源を演奏する条件ではない。同じseedでも異なるモデル間で同じ動きになるとは限らない。
二本目を作る場合は、起動・取得・初回生成と二本目の時間を分ける。

評価は顔・衣装・絵柄の維持、右手の交互の指弾き、左手の押弦と移動、指の破綻、
ベース本体・ネック・弦・ペグの変形、背景のちらつき、音の自然さ、見える動作と音の対応。
同じ時刻のフレームシートと実際の動画を使う。静止画や音声ストリームの存在だけで、
音楽の品質や演奏同期が確認できたとはしない。手指の小ささ・細い弦には目視評価の限界がある。

共有ライブラリは先に検索したが、5分以上応答がなくタスク所有の検索プロセスを終了した。
検索結果は未取得であり、「該当素材なし」とは判定していない。

## 実行と予算

前回の航空機比較の上限6 CUとは別の実験。今回の数値予算を人が選ぶまでGPUを起動しない。
起動・モデル取得・失敗も上限に含め、各セッションは30分まで。予算・残時間が不足したら
本数を減らして停止する。失敗時の追加割り当て、GPU・モデル・精度の変更は自動で行わない。

`run.ts` は引数なしでローカルの計画だけを作る。`--one-seed` は提案B。
実行には選択と一致する `--execute --budget-cu 6` または `--one-seed --execute --budget-cu 4`、
解決済みAsk ID・予算・seed・40桁のソースcommit・必須ファイルのSHA-256を持つ
`outputs/execution-source.json` が必要。承認前にはこの実行許可記録を作らない。

実行時は本準備をコミットした版を別フォルダに展開し、そのクリーンな実装を固定する。
作業ツリーにある音声ガイド等の未コミット変更を混ぜない。画像とモデル版を照合し、
既存・孤立・不明なColab割り当てがあれば変更せず停止する。
GPUはモデル取得より先にCUDAで確認する。新旧それぞれのハードウェア証拠、boot記録、
要求・生成receipt、ComfyUI履歴、ダウンロード前後のハッシュ、所要時間とCUを保存する。

`outputs/execution.started` を一度だけ作成し、存在すれば再実行を拒否して証拠を保持する。
`finally` でこの試行が確保したVMだけをguard経由で停止する。停止状態、料金率0、孤立なし、
直接確認した割り当てなしをすべて確認してから次のモデルへ進む。
表示残高差と稼働時間による概算は分けて報告し、課金確定額とは呼ばない。

通常の画像参照生成はFastH3を第一候補にする方針を `AGENTS.md` と `docs/DESIGN.md` に反映した。
互換性のためCLIの省略時モデルは従来のまま。モデルは明示して選び、未対応の生成方式にはH3を使う。
