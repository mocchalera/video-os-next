【そのまま試せる依頼例】
目的：次の定例会の準備です。
材料：添付したメモのみを根拠にしてください。
出力：要点3つ、未決事項、担当と期限の表。各要点に資料名と該当箇所を付けてください。
資料にない事実・担当・期限は推測せず「不明」としてください。
任せる範囲：下書きの作成まで。送信・公開・他アプリの変更はしないでください。

最初の30分は、5分で仕事と材料を選び、15分で下書きを作り、10分で元資料と照合。準備時間と修正回数を記録すると、次に任せる仕事を選びやすくなります。

【制作に使ったツール・モデル】
・構成、調査、台本、編集コードの制作：OpenAI Codex
・実画面の取得・ブラウザ確認：AGI Cockpitの内蔵ブラウザ
・編集：Video OS Next（vos）。timeline.jsonとassets.jsonで映像・音声・字幕を管理
・図解とモーション：HTML / CSS / GSAP
・映像レンダリング：HyperFrames 0.7.60
・エンコード、音声ミックス、音量調整：FFmpeg 8.1.2
・ナレーション：Google Gemini 3.8 Flash TTS（gemini-3.8-flash-tts）、声はKore。公式Gemini Interactions APIで生成したAI音声
・音声の文字起こしと字幕時刻の照合：ローカルのfaster-whisper 1.2.1 / Whisper small
・制作スクリプト：Python / Node.js

【作り方】
1. 公式発表と利用手順を確認し、最初に試す仕事から19場面の台本を作成。
2. Work・Spaceの実画面を取得。アカウント情報や既存の会話・ページ名が映らないように切り出し。
3. 公開されたOpenAI公式デモ・製品画像を、実画面と区別して表示。
4. 台本からGemini 3.8 Flash TTSで日本語ナレーションを生成。
5. 音声の単語時刻を取得し、台本を元にした71個の字幕と場面切り替えを同期。
6. HTMLの図解をvosのタイムラインで合成。1080p・30fpsで書き出し、音量を-16 LUFSに調整。レイアウト、字幕時刻、映像と音声を検査。

Workへの入力は未送信の依頼例です。Dotsなどの公開デモはOpenAI公式素材であり、この動画で実行した業務の成果物ではありません。機能の提供時期・利用可否はプラン、地域、管理者設定で変わります。利用時は公式ページと自分のアカウントの表示をご確認ください。
