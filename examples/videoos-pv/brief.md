# videoos-pv — Video OS の 60 秒 PV

## Intent
素材フォルダと一言から、エージェントが粗編集まで進める。最後の一手は人間に返す。
その流れ（見る → 探す → 組む → 磨く → 届ける）を、Video OS 自身の実 artifact と
Video OS で編集した実作品だけで見せる。

## Audience
AI で映像編集を効率化したい人 / 大量素材を抱えるプロの映像クリエイター。

## Must have
- 画面の事実（Marlin 描写・検索結果・タイムライン・レビュー）は artifact にバインド
- 全カットを 120 BPM の拍に乗せる
- 権利クリーンな音楽（tools/bgm.py で合成）

## Must avoid
- 捏造した数値・引用の言い換え
- 読み切れない速さのテキスト
